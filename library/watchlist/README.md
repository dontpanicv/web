# Watchlist

A shared watchlist (V + Pavla): movies, documentaries, and series.

## How to add items
Create a new markdown file per item:
- `YYYY-MM-DD--slug.md` (preferred)

Include:
- Title
- Type (movie / documentary / series)
- Where to watch
- Why we want to watch it
- Notes (length, language, trailer link, etc.)
